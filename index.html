01 About

Origin

I'm a junior software developer in Bloemfontein, South Africa, with a foundation in full-stack web development and game engineering — and a habit of building the thing from scratch to understand how it actually works.

That's how the 2D game engine happened: a custom game loop, sprite renderer and collision system in C#/MonoGame, rather than reaching for someone else's. On the web side I've built Python backends behind React frontends, designed normalised relational databases, and during my internship at SocialSines shipped a leaderboard API and reusable UI components. I'm Microsoft certified on Azure (AZ-204, AZ-900, DP-900) and care about writing things that hold up at scale.
